New MIDI preset

Create a reusable preset, then drag it from the library onto the timeline.

Messages

Messages send in order. Channels: 1–16. All other values: 0–127. Program 0 selects the first program. For bank select, add CC 0 and/or CC 32 before the program change.

Use Download edited copy to save your presets with the library. Reloading discards edits.

Edit section

Each chord defaults to 4 beats when this section has no chordbeats instruction. To set different timing, add a line such as {chordbeats: 4 4 4 4} after the chords, before the next section label. Blank lines between lyrics or after a section label are allowed.

These beat values are assumed. adds a chordbeats instruction to the section text. Save the section to keep it in your edited copy.

The edit applies to every occurrence of this named section in the arrangement. Download an edited copy to keep your changes.

Library check

Review fixes for the complete library. Section headings use Verse 1:: text, one space, a number and one colon. Bracketed headings and common comment headings can be converted; chord tags are kept. Unlabelled songs receive a generic Song 1: heading, without guessing verses or choruses.

Existing MIDI events and explicit timing are preserved. Ambiguous references are reported for review. Changes stay in memory until you use Download edited copy.
